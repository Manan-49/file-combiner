How it works

Turn a codebase into useful AI context in three steps.

  1. 1

    Select a folder or files

    Drop a project folder, browse for a directory, or choose individual text files. Nested folders dropped from supported browsers are read recursively.

  2. 2

    Keep the relevant context

    Use the Standard preset to skip dependencies, builds, locks, caches, and environment files. Search, filter, or paste paths to make a focused selection.

  3. 3

    Create and review the prompt

    Choose Markdown, XML, or plain text, inspect the estimated context size, then copy or download the result. Always review it before sharing.

Privacy and safety

Your code stays on your device.

File Combiner uses browser file APIs to process the files you choose. The app does not send their contents to a server, require a login, or include analytics that inspect project data. The optional offline app cache contains only this website’s static files—not your project.

Privacy tools reduce risk; they do not replace review. The Standard preset omits common .env files, and the optional masking step replaces likely credential values in generated output. Confirm that the final output is appropriate for the destination before pasting it into any third-party service.

FAQ

Questions about this code file combiner.

Does File Combiner upload my code?

No. It combines selected files locally in the browser. The generated result only goes where you choose to copy or download it.

Which files can I combine?

Text-based source files, documentation, and configuration files work well. Known binary formats are skipped so they do not pollute your prompt.

Can I use the output with ChatGPT, Claude, Gemini, or another AI tool?

Yes. Markdown is a good general default; XML can make file boundaries clearer for some workflows, and plain text is available when you need the smallest wrapper.

Is the token count exact?

No. It is a practical character-based estimate. Every model and tokenizer differs, so leave room below a provider’s actual context limit.

Can the secret safeguard guarantee safe output?

No. It masks several common credential shapes but cannot identify every secret or every sensitive business detail. Review the final content before sharing it.
